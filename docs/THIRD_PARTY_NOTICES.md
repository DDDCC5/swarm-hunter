# Dependencies and asset notes

- The application uses PICO Spatial SDK, Android, AndroidX/Compose and Kotlin. Dependencies are resolved through Gradle and remain subject to their respective terms. The repository does not include PICO SDK source or local SDK installations.
- Android/Gradle scaffold and wrapper files originate from the project toolchain/template. Existing copyright notices in those files are preserved.
- GLB models, UI bitmaps, effect media and audio under `app/src/main/assets` are project outputs. They are included for running and reviewing this game. Generation tools/model weights and local development caches are not included.
- Voice guidance was generated offline during development; this repository distributes the resulting WAV assets, not the underlying speech model weights.
- No project-wide open-source license has been selected. Public repository visibility alone does not replace a license grant. Third-party dependencies retain their own licenses.
