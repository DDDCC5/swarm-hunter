# 虫潮猎手 1.3.2

开发体验版（debug），versionCode20，包名 `com.example.swarmhunter`。

- **手势连发**：当前手型匹配注册手势才持续发射；失配或失追立即停止新增射击。左右手独立冷却，蛛丝0.20秒、激光0.15秒、能量弹0.32秒、脉冲0.55秒；重新做手势不能绕过冷却。
- **注视布置机关**：视野中心选择已扫描平面，任一手双指捏合确认；墙面竖贴，地面/桌面平放，支持预览和撤销，避免边缘、面板遮挡及重复放置。
- **模型和猎具**：八种虫类使用Tripo来源模型；四款护腕重新设计并按功能配色，固定外露部件、保留内置限位动画，并从真实炮口发射。
- **出场与节奏**：可见出洞动作与专属声音由同一事件触发，不再等转头显形。虫体线性尺寸较1.6倍显示缩小约44%，巢穴按体型缩小；支持地面、墙面和已扫描天花板，开局更稀疏并渐进加密。
- **运动与死亡**：贴面步幅及墙地/顶墙转角优化；死亡先完整播放1秒翻倒收腿，随后消散淡出，到1.7秒清理。墙顶尸体下落，各虫种使用独立出场录音和不同节奏。
- **练习与反馈**：可选无伤射击练习、三档难度、命中/击杀反馈、命中率及机关击杀统计。

108项单元测试、debug构建通过；头显和模拟器通过原生模型/死亡动画、音频、地墙顶朝向与射线检查。真实音画同步、复杂空间交互、舒适度和持续性能仍待实机体验验收。
